# 驾驶舱设计规范

驾驶舱和审核流水线使用同一套页面骨架。新页面先复用 `_page`，不要另写颜色、字号或按钮样式。

## 页面

- 语言是 `zh-CN`，字体是 `PingFang SC`。
- 页面背景 `#f6f3ec`，正文 `#243036`，辅助文字 `#66717a`。
- 内容最大宽度 980px，左右留 20px。
- 标题 36px，字距 `-0.04em`，标题不换行。
- 卡片、表单和空状态都用白底、`#e4ddd0` 边框、8px 圆角。

## 动作

- 主按钮使用 `#0f6b4c` 白字，一次区域只放一个主动作。
- 次按钮使用 `#e7f4ee` 绿色文字，例如“建议”“状态”“移除”。
- 阶段标签使用同样的浅绿底和绿色文字。
- 链接使用 `#0f6b4c`，不使用下划线。

## 审核流水线

- 标题固定为“审核流水线”。
- 任务和审核记录按时间放在同一列，最新状态使用阶段标签。
- 只刷新 `#pipeline` 内容，每 5 秒一次；页面滚动位置保持不变。
- 评论正文放在限高的阅读区，不把整篇审查压成一行。
- 底部动作栏固定在视口下方。运行中的任务显示“正在处理”。
- 底部动作区沿用驾驶舱的表单栏。审查是主按钮，建议和状态是次按钮。
- 流水线不提供合并按钮。汇入仍由有权限的人在 Gitee 上完成。

## 禁止

- 不在页面展示数据库地址、令牌或密钥。
- 不把模型输出的“批准”展示成工厂判定。
- 不在窄屏隐藏操作；720px 以下改为纵向排列。
