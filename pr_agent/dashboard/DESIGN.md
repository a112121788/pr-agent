# 驾驶舱设计规范

驾驶舱和审核流水线使用同一套页面骨架。新页面先复用 `_page`，不要另写颜色、字号或按钮样式。

## 页面

- 语言是 `zh-CN`，字体是 `PingFang SC`。
- 页面背景 `#f6f3ec`，正文 `#243036`，辅助文字 `#66717a`。
- 内容最大宽度 980px，左右留 20px。
- 标题 36px，字距 `-0.04em`，标题不换行。
- 卡片、表单和空状态都用白底、`#e4ddd0` 边框、8px 圆角。

## 动作

- 主按钮使用 `#0f6b4c` 白字，一次区域只放一个主动作。
- 次按钮使用 `#e7f4ee` 绿色文字，例如“建议”“状态”“移除”。
- 阶段标签使用同样的浅绿底和绿色文字。
- 链接使用 `#0f6b4c`，不使用下划线。

## 审核流水线

- 标题固定为“审核流水线”，标题不换行。
- 标题下写明编号、标题、作者、源分支、目标分支和开放状态，并链到 Gitee。
- 阶段条标出已经出现的阶段，并用描边标出当前段。当前段下面有一句下一步。
- 任务和 Gitee 评论按时间放在同一列。普通评论和“审查失败”也显示，不能因为不是工厂记录就留白。
- 短评论直接展开。长评论默认收起，点“展开正文”后跟页面一起滚动，不在卡片里再套一层滚动条。
- 只在内容变化时替换 `#pipeline`，每 5 秒检查一次；页面滚动位置保持不变。
- 底部动作栏固定在视口下方。审查是主按钮，建议和状态是次按钮。
- 点击动作不整页跳转。按钮变为“排队中”并暂时停用，流水线里立刻出现任务。
- 运行中的任务显示“正在处理”。流水线不提供合并按钮。汇入仍由有权限的人在 Gitee 上完成。

## 禁止

- 不在页面展示数据库地址、令牌或密钥。
- 不把模型输出的“批准”展示成工厂判定。
- 不在窄屏隐藏操作；720px 以下改为纵向排列。
