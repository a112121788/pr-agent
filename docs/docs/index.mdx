## Quick start

Gitee PR-Agent is the core machine of the review factory. It collects evidence for one Gitee pull request. A person still writes the verdict, and Gitee still performs the merge. The default model is `gpt-6.1-sol`, with `glm-5.3` as the fallback.

```bash
docker run --rm -it \
  -e OPENAI__KEY=<your_openai_key> \
  -e OPENAI__API_BASE=https://your-gateway.example/v1 \
  -e CONFIG__GIT_PROVIDER=gitee \
  -e GITEE__PERSONAL_ACCESS_TOKEN=<your_gitee_token> \
  ecloud-tcr.tencentcloudcr.com/ecloud_project/pr-agent:latest \
  --pr_url https://gitee.com/owner/repo/pulls/7 review
```

The same command accepts an enterprise URL:

```text
https://e.gitee.com/<enterprise>/repos/owner/repo/pulls/7
```

Comment `/review`, `/improve`, `/describe` or `/ask` on the pull request. `/review` publishes **PR 审查指南**, and `/improve` publishes **PR 代码建议**. Gitee cannot commit the suggested code, so both results stay as comments.
