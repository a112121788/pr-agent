## Quick start

Review a Gitee pull request from your terminal. All you need is an OpenAI key, an OpenAI-compatible API base, and a Gitee token.

```bash
docker run --rm -it \
  -e OPENAI__KEY=<your_openai_key> \
  -e OPENAI__API_BASE=https://your-gateway.example/v1 \
  -e CONFIG__GIT_PROVIDER=gitee \
  -e GITEE__PERSONAL_ACCESS_TOKEN=<your_gitee_token> \
  ecloud-tcr.tencentcloudcr.com/ecloud_project/pr-agent:latest --pr_url <gitee_pr_url> review
```
