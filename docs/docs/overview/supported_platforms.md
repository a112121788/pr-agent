---
title: "Supported platforms"
sidebar_position: 3
---

This build supports Gitee only. Use the [Gitee installation guide](../installation/gitee.md) to configure the token, webhook, and Docker service.

The CLI accepts a Gitee pull-request URL. GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Gerrit, CodeCommit, local Git, and plain-diff mode are not available.
