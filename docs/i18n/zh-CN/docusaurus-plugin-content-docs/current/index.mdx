## 快速开始

在终端里审查一个 Gitee 拉取请求。准备一个 OpenAI 密钥、一个 OpenAI 兼容的 API 地址和一个 Gitee 令牌即可。

```bash
docker run --rm -it \
  -e OPENAI__KEY=<your_openai_key> \
  -e OPENAI__API_BASE=https://your-gateway.example/v1 \
  -e CONFIG__GIT_PROVIDER=gitee \
  -e GITEE__PERSONAL_ACCESS_TOKEN=<your_gitee_token> \
  ecloud-tcr.tencentcloudcr.com/ecloud_project/pr-agent:latest --pr_url <gitee_pr_url> review
```

<div className="pra-cta-row">

[安装到你的仓库](pathname:///installation/) [在本地运行的其他方式](pathname:///installation/locally/)

</div>

已经安装好了？在拉取请求中评论 `/help "your question"`，PR-Agent 会根据这些文档回答。
