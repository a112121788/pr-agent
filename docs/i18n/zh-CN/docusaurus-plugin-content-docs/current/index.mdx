## 快速开始

在终端里审查一个拉取请求。准备一个 OpenAI 密钥和一个 GitHub 令牌即可。

```bash
docker run --rm -it \
  -e OPENAI__KEY=<your_openai_key> \
  -e GITHUB__USER_TOKEN=<your_github_token> \
  pragent/pr-agent:latest --pr_url <pr_url> review
```

<div className="pra-cta-row">

[安装到你的仓库](pathname:///installation/) [在本地运行的其他方式](pathname:///installation/locally/)

</div>

已经安装好了？在拉取请求中评论 `/help "your question"`，PR-Agent 会根据这些文档回答。
