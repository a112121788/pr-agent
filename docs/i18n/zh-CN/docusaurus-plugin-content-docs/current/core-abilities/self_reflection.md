PR-Agent 实现了**自我反思**过程：AI 模型反思、打分并重新排序自己的建议，剔除无关或不正确的建议。
这种方法提高建议的质量和相关性，节省用户时间并改善体验。
配置选项允许用户设置分数阈值，以进一步过滤建议。

## 介绍——用层次化呈现实现高效审阅

并非所有生成的代码建议都相关，因此必须让用户能够快速、高效地审阅它们，迅速识别并过滤不适用的建议。

为实现这一目标，PR-Agent 在向用户呈现建议时提供专用的层次结构：

- “category” 节按类别分组建议，使用户能够迅速忽略无关建议。
- 每条建议首先用一行摘要描述，点击可折叠区域可以展开为完整描述。
- 展开建议后，用户会得到更全面的描述，以及演示该建议的代码片段。

:::note[快速审阅]
这种层次结构旨在便于快速审阅每条建议，用户平均在每项上花费约 5–10 秒。
:::

## 自我反思与重新排序

AI 模型最初的任务是生成建议，并按重要性顺序输出。
但实践中我们观察到，模型往往难以在单次过程中同时生成高质量代码建议并把它们排好序。
此外，最初生成的建议集合有时包含容易识别的错误。

为解决这些问题，我们实现了“自我反思”过程，用于改进建议排序并剔除无关或不正确的提议。
该过程包含以下步骤：

1. 在后续调用中把生成的建议呈现给模型。
2. 指示模型按 0–10 分为每条建议打分，并给出所赋分数的理由。
3. 利用这些分数重新排序建议，并过滤不正确的建议（分数为 0）。
4. 可选地，过滤掉所有低于用户定义分数阈值的建议。

请注意，同时呈现所有生成的建议为模型提供了全面上下文，使其能够比逐条单独评估做出更有依据的决定。

总之，自我反思过程使 PR-Agent 能够按重要性优先排序建议，剔除不准确或无关的提议，并可选地排除低于指定重要性阈值的建议。
这为用户带来更精炼、更有价值的建议集合，节省时间并改善整体体验。
